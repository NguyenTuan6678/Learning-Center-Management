# 🎓 Learning Center Management

## 📌 Overview

**Learning Center Management** is a web-based application designed to efficiently manage the operations of an educational center. The system provides tools for handling students, classes, schedules, billing, and academic records in a centralized and organized way.

This project aims to simplify administrative tasks, improve data management, and enhance the overall workflow for both administrators and staff.

---

## 🚀 Features

- 👨‍🎓 **Student Management** – Add, update, and track student information
- 🏫 **Class Management** – Organize classes, assign students, and manage enrollments
- 📅 **Schedule Management** – Manage class schedules with time and date tracking
- 💰 **Billing System** – Handle student payments and billing records
- 📊 **Grade Management** – Record and manage student grades
- 🔐 **Authentication & Authorization** – Secure login and role-based access control

---

## 🛠️ Technologies Used

- **Frontend:** React (Vite), Redux Toolkit, Axios
- **Backend:** Spring Boot
- **Database:** PostgreSQL

---

## 🎯 Objectives

- Streamline the management of learning centers
- Reduce manual administrative workload
- Provide a scalable and maintainable system structure

---

## 📂 Project Structure

The project follows a modular and feature-based structure to ensure scalability and maintainability.
